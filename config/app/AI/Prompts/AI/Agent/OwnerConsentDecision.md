This registry entry names the agent's owner-consent decision call for cost booking and usage logging. It is not a prompt: the call goes to a System One decision model (TypeSafe Jev via OpenRouter `/api/v1/systemone`) whose two questions are built in code by `DDD\Domain\AI\Repo\Argus\Conversations\Decisions\ArgusAgentOwnerConsentDecision::buildQuestions()` — two `noul`: did the assistant name exactly this step (its target) and its consequence before the owner's answer, and did the owner explicitly agree to exactly this step afterwards? The tool builds the step and the consequence from what it loaded; the dialogue is pulled from the conversation's own rows. Both answers must reach the threshold (0.90 for every kind — owner 2026-10-19), and every failure is no consent. This text is never sent to the model.
