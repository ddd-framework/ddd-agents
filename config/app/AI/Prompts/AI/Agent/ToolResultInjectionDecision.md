This registry entry names the agent's tool-result INJECTION screening call for cost booking and usage logging. It is not a prompt: the call goes to a System One decision model (TypeSafe Jev via OpenRouter `/api/v1/systemone`) whose one question is built in code by `DDD\Domain\AI\Repo\Argus\Conversations\Decisions\ArgusAgentToolResultInjectionDecision::buildQuestions()` — one `noul` per chunk of an untrusted tool result (web page text, mentions, competitor posts, social comments): does it contain an instruction aimed at an AI assistant? On a hit the screening job replaces the stored result with a removal notice. This text is never sent to the model.
